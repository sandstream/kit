### Security

- **`kit gate-bash` blocks a prebuilt binary install until `kit triage release` has checked the download.** A download followed in the same command by an extract and a run, a `chmod +x`, a build in the extracted tree, a move onto PATH (`/usr/local/bin`, `~/.local/bin`, `~/bin`, `$HOME`, `%LOCALAPPDATA%`, `C:\Program Files`) or `install` passed silently, while `npm i -g` was held by the cooling period and `curl … | sh` was refused. The gate now reads curl, wget, `gh release download`, PowerShell `Invoke-WebRequest -OutFile` and `Start-BitsTransfer`, then tar, unzip, 7z, gunzip and `Expand-Archive`, and blocks the chain with exit 2 unless `.kit-triage.jsonl` holds a `release` receipt for that URL from the last 7 days. The message names the exact `kit triage release <url>` command. A bare download is not blocked. A chain it cannot read (an expanded URL or file name, `gh release download` with a glob) is refused. A source tarball built after `cd` into it counts as running it; a dataset extracted beside your own `make` or `python train.py` does not. Tested on Linux, with the PowerShell cases running on the Windows CI shards; macOS is unverified. Found by kit-research#233 (G1).
