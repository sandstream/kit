### Fixed

- **`kit triage mcp` now flags a dangerous capability written in a parameter description.** The dangerous-capability heuristic read only the tool name and description, so "One item with spaces is run as a shell line." was flagged in a tool's description and passed when the server put it on a parameter. kit now also reads every parameter description in `inputSchema`, through nested properties, array items, unions and `$defs` up to the existing depth bound of 32, plus enum value descriptions (`enumDescriptions`, `markdownEnumDescriptions`, `x-enumDescriptions`, `x-enum-descriptions`). Each finding names the parameter path, for example `param:check[]` or `param:opts.mode.enumDescriptions[1]`. Enum value descriptions are also run through the poisoning detector now. The finding stays heuristic and does not change the verdict. Found by the kit-research note shrink-anything-vs-kit.
