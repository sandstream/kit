### Security

- **`kit triage npm` reports a bin named after another package, and the install gate refuses `npx <bin>` on it.** `@metaharness/redblue` ships a bin `redblue`; without a local install `npx redblue init` fetches the unrelated unscoped `redblue` (2017, another maintainer), and `gate-bash` allowed it with exit 0. Triage now checks every bin whose name is not the package's own and reports `other` (with the owner's maintainers and creation date) or `unclaimed` (404, anyone can register it) as a warning, and writes an `npm-bin` record to `.kit-triage.jsonl`. `gate-bash` refuses `npx`, `npm exec`, `pnpm dlx`, `yarn dlx` and `bunx` of such a name and names the scoped package to install, or `npx -p @scope/pkg <bin>`. A local bin, or a newer PASS for the unscoped name itself, still allows it. Found by kit-research `metaharness-artex-defense-vs-kit`.
