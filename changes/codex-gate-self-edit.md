### Security

- **The gates now refuse an agent's edit that unwires kit's Codex gate, as they already did for Claude Code's.** After `kit agent-config`, `gate-bash` passed `sed -i '/gate-bash/d' .codex/config.toml`, `rm .codex/config.toml` and `printf x > .codex/config.toml` with exit 0, and `gate-env` passed a Write that replaced the file, while the same edits to `.claude/settings.json` exited 2. Codex reads hooks from `config.toml` and `hooks.json` in the project's `.codex/` and in `$CODEX_HOME` (default `~/.codex`); when any of the four holds kit's gate hook, `gate-bash` refuses a shell write or delete onto them, and `gate-env` refuses a Write/Edit whose result drops or changes that hook (event, matcher or command), does not parse, or cannot be computed. An edit that keeps the hook passes. Codex's own `apply_patch` tool has no kit gate, so an edit made through it is not seen. Found by kit-research#241.
