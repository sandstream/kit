### Fixed

- **A bare `kit secrets rotate <KEY>` now points to `--from-cli` instead of a pull request that already shipped.** It said "Per-service rotation (Stripe/AWS IAM/GCP) coming in PR R3."; those playbooks ship as `kit secrets rotate <KEY> --from-cli`, and the hint now names that command with the key filled in. Found by kit-research#232.
- **The Stripe `--from-cli` playbook no longer prints a Stripe CLI command that does not exist, or a timestamp no shell expands.** It printed `stripe api_keys create … --description 'kit-rotated $(date +%FT%T)'`: the single quotes stopped the expansion, the line was POSIX-only, and Stripe's CLI reference (https://docs.stripe.com/cli) has no `api_keys` command. Stripe documents creating, rotating and expiring keys on the Dashboard's API keys page (https://docs.stripe.com/keys), so the playbook now gives those steps, with a key name whose timestamp kit computes (`kit-rotated-2026-11-26T09:08:07Z`), and links to Stripe's rotation section. Found by kit-research#232.
