### Fixed

- **kit no longer prints "SQLite is an experimental feature" on every call, each PreToolUse gate included.** Thirteen modules in the CLI's static import graph imported `node:sqlite` as a value, so Node 22 loaded it, and printed its `ExperimentalWarning` to stderr, on `kit --version`, `kit gate-bash`, `kit gate-env` and `kit gate-egress` though none of them opens a database (kit-research#233, E1). Production code now imports only the `DatabaseSync` type and opens databases through `openSqlite()` in `src/utils/sqlite.ts`, which loads `node:sqlite` on first use. `src/sqlite-lazy-load.test.ts` runs the gates and checks that `node:sqlite` was not loaded, and fails on any other value import or `require` of it in `src/`. A gate deny still loads it: its audit event is written under the SQLite-backed audit write lock. The memory modules' JavaScript still loads with `cli.js`, which imports every command statically.
