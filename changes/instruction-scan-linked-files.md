### Fixed

- **The instruction rules read the files a skill sends the agent to.** `kit triage instructions` and `kit triage skill` read fixed file names only, so a `SKILL.md` that says "for phase two, read PHASE2.md", or keeps its instructions in `references/format.md`, had those files left unread while the skill report said the rules read "the same files". Beside each `SKILL.md` the scan now reads the `.md` files it links or names and every `.md` file in its `references/` directory (one hop, inside the skill directory, at most 20 per skill, the rest reported as a coverage gap), and the count says how many were read that way (`2 file(s) read (1 linked from a SKILL.md or in its references/)`). `--json` lists them as `companions`.
- **`exfil-imperative` no longer fires on a form schema.** `email: z.string().email(),` above `password: z.string().min(8),` matched as "email … password", a high-confidence finding (and a memory quarantine). The pair is now skipped when both words are names in code (a key, a property or a call); an exfil verb or a secret noun used as a word still fires.
