### Fixed

- **`gate-bash` now sees a nested agent with approvals off when herdr launches it.** `herdr pane new --kind claude -- … --permission-mode bypassPermissions` and `herdr pane new --kind codex -- … -s danger-full-access -a never` passed with exit 0, while the same flags on a bare `claude` or `codex` were refused. The shared carrier reader (`gate-bash-carriers`) now reads `herdr … --kind <agent> -- <argv>` as that agent's own argv, and `herdr … -- <cmd …>` as the command it starts, so every agent the nested-agent rule covers is refused the same way through herdr; the GitHub token-action rule reads through it too. herdr commands without `--` (`herdr pane list`) still pass. Launchers that set the mode in their own settings (Orca, Paseo, T3 Code) are not covered. Found by kit-research `copybook-vs-kit`.
