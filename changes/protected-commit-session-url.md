### Fixed

- **The public-artifact rule and its checks now cover commit messages.** CLAUDE.md and AGENTS.md forbade an agent session URL only in issue and PR text, and both checks read only the PR title and body, so a session link in a commit trailer reached the public history unchecked. The rule now names commit messages; `scripts/prepush.mjs` checks the branch's commits (`origin/main..HEAD`), and the PR hygiene workflow reads the PR's commits over REST and names each offending commit without echoing the URL. A commit list it cannot read fails the step. Commits already on `main` are not rewritten.
- **`scripts/prepush.mjs` no longer passes the PR-text check when it could not look the PR up.** It used `gh pr view` (GraphQL), which agent sessions refuse; the refusal was reported as "no open PR" with a pass. The PR is now found through `gh api repos/{owner}/{repo}/pulls` with a `head` filter, and a lookup that fails is shown as not run (`!`, failing under `--strict`).
