### Added

- **`kit triage skill` is measured against OpenAI's labelled skill-review corpus.** The nine cases of `openai/codex-security`'s `evals/check-skills` (Apache-2.0, commit `256cddf5`, with LICENSE and NOTICE) are vendored as data in `fixtures/third-party/openai-codex-security-skill-cases/`, each with the PASS / REVIEW / BLOCK / INCOMPLETE label upstream expects. `src/triage-labelled-skill-corpus.test.ts` writes each case to a temporary directory, checks its bytes against upstream's sha256, runs the real skill triage on it, and prints the recall line: today 5 of 9 cases in the expected direction and **0 of 2 BLOCK cases caught**. The four misses are listed as known gaps with their cause (a linked `references/format.md` that is not read, render-time `` !`cmd` `` with no rule, a `SKILL.md` naming a file triage was not given, a mutable remote page directing tools). A known gap that starts matching fails the test until its entry is removed, so the number only moves on purpose. The cases are stored as JSON so that kit's scans of its own tree, and agent harnesses, never read them as kit's skills or code.
