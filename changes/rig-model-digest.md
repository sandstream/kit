### Added

- **`kit rig` ingest rows may carry an optional `model_digest`, so one label can no longer hide two models.** A row's `model` and `model_version` are free text, and a run labelled `model_version: "latest"` against different weights counted as the same instrument; a `model_digest` key was refused as unknown. The caller may now declare `"model_digest": "<scheme>:<value>"` (for example `sha256:<64 hex>` or `snapshot:<id>`). kit checks only its shape, refuses one run of a target declared with two digests, keeps it in the stored findings that the receipt signs by hash, lists the instruments per config in `result.json` and `kit rig report`, and warns when one model and version label covers two digests or digested and undigested runs. It is never required, never computed or verified, and never changes a finding's adjudication or any number: every report that shows a digest says it is self-declared. ADR-0007 is amended to say so. Found by the kit-research note `calculus-of-association-vs-kit`.
