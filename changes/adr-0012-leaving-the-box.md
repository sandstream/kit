### Added

- **Proposed ADR-0012: an action that leaves the box is a gated action.** This covers network egress, a force push or a push to the default branch, a merge through the forge, publishing, and a change to a forge's secrets, variables or workflow runs. The ADR states what kit enforces today and points at the code and tests: `gate-bash` refuses force pushes, pushes to `main` or `master`, package publishes and production deploys, and the opt-in `gate-egress` refuses URL and host targets outside a signed scope. It also lists what kit does not enforce, measured on `main`: `gh pr merge`, the merge API, `gh secret set`, `gh workflow run`, `gh release create` and `gh auth token` all pass. The ADR is proposed and gates nothing until the owner accepts it. Found by the kit-research note `agent-vm-yolo-herdr-paseo-vs-kit`.
