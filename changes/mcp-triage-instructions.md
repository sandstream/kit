### Fixed

- **`kit triage mcp` now reads and pins the server's `instructions`.** MCP clients put the `instructions` text of the server's `initialize` result into the agent's context, but triage read only `tools/list`: a server that rewrote its instructions to ask for whole file contents and kept its tools still reported "✓ tool set unchanged since pin". `--init <initialize.json>` (or an `instructions` key in the tools file) now runs that text through the same injection scan as tool descriptions and stores its sha256 in the pin as `instructionsHash`; a change fails the run as a rug pull. A pin written before reports "server instructions not pinned yet", and a run without the initialize result says "server instructions not read", never "unchanged". Found by kit-research `copybook-vs-kit`.
