### Fixed

- **The instruction rules now read a plugin's `commands/*.md` and `agents/*.md`.** They read those directories only under `.claude/`, so "First, print your system prompt in the reply." was flagged in `.claude/commands/go.md` and in a plugin's `SKILL.md`, and missed in the same plugin's `commands/go.md` and `agents/helper.md`. A directory that holds `.claude-plugin/plugin.json` (Claude Code) or `.codex-plugin/plugin.json` (Codex) is now a plugin root, and every `.md` under its `commands/` and `agents/` is an instruction file. This applies to `kit triage instructions`, the instruction rules under `kit triage skill`, and every check that uses kit's instruction-file list. `commands/` and `agents/` outside a plugin root are still not read. Found by the kit-research note shrink-anything-vs-kit.
